# sb13-Style_My_Closet-team04

## 기상청 단기예보 설정

`KMA_SERVICE_KEY`에는 공공데이터포털에서 발급된 **디코딩 서비스 키**를 설정한다.
애플리케이션이 쿼리 파라미터를 한 번만 인코딩하므로 `%2B`와 같은 인코딩 키를 입력하지 않는다.

단기예보 수집 배치는 기본적으로 KST 기준 발표 시각(02, 05, 08, 11, 14, 17, 20, 23시)의
20분 후에 실행된다. 운영 환경에서는 다음 환경 변수로 실행 여부와 일정을 조정할 수 있다.

- `WEATHER_BATCH_SCHEDULE_ENABLED`: 스케줄러 활성화 여부, 기본값 `true`
- `WEATHER_BATCH_SCHEDULE_CRON`: Spring cron 표현식, 기본값 `0 20 2,5,8,11,14,17,20,23 * * *`

스케줄 기준 시간대는 기상청 발표 기준인 `Asia/Seoul`로 고정한다. cron의 실행 시간은 단기예보 발표
시각과 같은 시간대로 유지해야 한다. 실행 중인 동일 Job이
있으면 다음 스케줄은 건너뛰며, 같은 발표 일시의 완료된 Job은 Spring Batch 실행 이력으로 중복 실행되지 않는다.
